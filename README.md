Iris K-Means Clustering

Project Description

This project uses the K-Means Clustering algorithm to group iris flowers based on their sepal length, sepal width, petal length, and petal width. It uses Python and machine learning to identify similarities between flowers.

Objectives

- Understand K-Means Clustering.
- Analyze the Iris dataset.
- Group similar flowers into clusters.
- Visualize the clustering results.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

Dataset

The Iris dataset contains measurements of iris flowers, including:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Algorithm

K-Means Clustering is an unsupervised machine learning algorithm that groups similar data points into clusters. This project uses three clusters to explore patterns in the Iris dataset.

How to Run

1. Clone or download this repository.

2. Install the required libraries:
   
   pip install pandas numpy matplotlib scikit-learn

3. Open the Jupyter Notebook.

4. Run all the cells to perform clustering and view the results.

Expected Output

- Three clusters of iris flower data.
- Graphical visualization of the clusters.
- Identification of similarities between flowers.

Conclusion

This project demonstrates how K-Means Clustering can be used to analyze the Iris dataset and group flowers based on their measurements.
